maca_debug.py针对常规模型和量化模型做了区分，启动时需要指定模型类型，使用方法如下：
一 常规模型
1 普通模式
  python maca_debug.py -i ./test.onnx   -t common -b 5 -s 1
  -b 指定每次比较的结果个数，默认为5，可不指定，例：当最终结果出现问题时，会计算所有node的snr，-b指定了一次计算的snr的node个数
  -t 指定模型类型，固定为common
  -s 指定了输入数据的batch，不指定则默认为1
  普通模式下，会首先比较最后一层的结果，如结果一致，不再进行中间层的比较。
2 指定模式
  python maca_debug.py -i ./test.onnx   -t common -m Concat_0,Conv_11
  -m 指定需要比较的中间节点的名称，可指定多个，以逗号分隔
  -t 指定模型类型，固定为common
  指定模式下，无论最后一层结果一致或不一致，都会进行指定节点的比较。

二 量化模型
使用方式与常规模型基本一致，区别有两点：
1 -t 参数固定为quantize
2 量化模型只会比较量化节点，指定模式下也只能指定量化节点的名称作为-m参数的输入
